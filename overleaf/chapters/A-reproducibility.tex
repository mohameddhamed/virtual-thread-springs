\section[Reproduction Overview and Open-Science Package]{Reproduction Overview and\\ Open-Science Package}
\label{sec:repro-overview}

In accordance with open-science standards and ELTE Faculty of Informatics thesis requirements, the complete empirical corpus supporting this dissertation has been frozen, audited, and cataloged within the repository under \texttt{docs/evidence-freeze/} and \texttt{results/}. The package encompasses 543 cataloged physical disk files totaling $1\,049.11\text{ MB}$ ($\approx 1.05\text{ GB}$), including raw k6 JSON lines streams, binary Java Flight Recorder (JFR) event files, process telemetry CSV logs, and execution manifests.
