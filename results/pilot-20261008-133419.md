## Interpretation

This pilot confirms that the benchmark harness, raw-output capture, manifest,
checksums, and JFR recording work together. It also shows that the serialized
payment critical section dominates mixed-workload tail latency even when no
pinning events are recorded in the refactored condition.

The k6 process returned status 99 because the existing reference p95 threshold
of five seconds was crossed. HTTP failures were zero; the non-zero status is
retained in the manifest instead of being suppressed. The result is therefore
usable as exploratory protocol evidence, not as a final performance claim.
